# ZOO-134 修复剪藏虚拟列表头插后的重叠与闪帧

## Goal

修复剪藏列表头插不同高度卡片后出现的坐标错位、互相覆盖与 hover 闪帧，同时确保卡片内容和操作始终绑定到正确剪藏 ID。

## Requirements

- 虚拟列表使用稳定剪藏 ID 作为 item identity，不按可变 index 复用实体测量。
- 新增剪藏插入顶部后，虚拟器必须重新计算受影响位置；有图与无图卡片可保持各自真实高度。
- 不修改剪藏 API、数据缓存协议或卡片视觉设计。
- 回查使用相同虚拟列表模式的兄弟入口，只在共享根因存在时一并修复。

## Acceptance Criteria

- [ ] 有图和无图剪藏混排时，头插任一类型均无重叠或空洞。
- [ ] hover、选中、刷新和滚动时不闪现其他剪藏的标题、摘要或图片。
- [ ] 卡片、菜单和选中态始终对应稳定剪藏 ID。
- [ ] 自动化测试覆盖头插导致 index 整体位移和不同卡片高度的场景。
- [ ] Web lint、相关单测、主题检查与生产构建通过。

## Out Of Scope

- 重做剪藏卡片或列表布局。
- 修改剪藏排序规则和新增接口。
- 用关闭虚拟滚动规避缓存问题。
