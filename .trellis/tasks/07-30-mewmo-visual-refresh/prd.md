# 官网主视觉与 App 浅色主题优化

## Goal

把官网重做为节奏明确的一屏一主题产品主页，让访客依次理解 mewmo 的基础能力、后台工作流与 mew Agent，并进入注册；App 端只把浅色主题的黄白 / 米黄色替换为中性灰阶。

## Requirements

### R1. 页面结构

- 页面依次为 Hero、基础能力、自动工作流、mew Agent、末尾 CTA、精简 Footer。
- Hero 左侧只显示 Logo、产品名 `mewmo` 和口号“AI 原生的一站式知识工作台”，右侧显示无私人数据、无标签 UI 的 Demo 工作区。
- Hero 不显示 CTA、说明段落、证明条或额外功能文案；注册入口只保留在导航。
- 基础能力不显示“基础功能”通用标题，使用左侧单选 Tab + 右侧说明和 Demo；顺序为笔记、剪藏、订阅、知识库，默认笔记。
- 自动工作流使用相同交互模型，顺序为文章总结、笔记洞察、相关推荐，默认文章总结。
- mew Agent 使用独立黑色全宽场景，不使用左右分栏或 Tab，以一次完整 Agent 执行为主体。
- Agent 当前能力与未来路线必须明确区分；长期记忆、自定义 Skill、Automation、日报 / 周报、主动回顾 / 提醒统一标记“即将支持”。

### R2. 导航与链接

- 右侧顺序固定为 Globe 图标、登录、注册、GitHub；不显示“产品”锚点。
- Globe 控件保留现有中英文切换行为和可访问名称。
- GitHub 位于最右侧，链接到 `https://github.com/ZOO-AiiiPM/mewmo` 并在新窗口打开。
- 中英文文案结构完整对应。

### R3. 视觉与 Demo

- 页面色彩节奏固定为：Hero 黑、基础能力白、自动工作流浅灰、Agent 黑、CTA 白。
- 不使用黄色、米色、彩色强调、渐变、装饰 blob、卡片墙、嵌套卡片或滚动吸附。
- Demo 名称统一为 `Demo`，主题为“如何建立一套持续运转的个人知识系统”。
- Demo 以受控 HTML/CSS 产品画面展示 Markdown 笔记、网页剪藏、RSS、知识库、自动总结、洞察、推荐及 Agent 行动，不使用私人内容或已取消标签。
- 桌面首屏左右分栏，移动端文字在上、产品画面在下；Tab 在移动端横向滚动。
- 动效只用于首屏顺序进入、Tab 内容淡入和 Agent 流程显现，并尊重 `prefers-reduced-motion`。

### R4. App 浅色主题

- 仅将现有浅色语义 token 的黄 / 米色替换为白、灰、黑，保持 dark theme、布局、主题状态与业务行为不变。
- hover、selected、raised 与边界仍需通过明度差清晰可辨。

## Acceptance Criteria

- [ ] Hero 只有品牌、口号和 Demo 工作区，无 Hero CTA 或额外说明。
- [ ] 基础能力与自动工作流 Tab 的顺序、默认值、键盘与点击交互符合要求，切换时布局不跳动。
- [ ] Agent 区展示检索个人知识、引入网络信息、形成洞察、提出写入、用户确认的完整流程。
- [ ] 未上线能力均明确标记“即将支持”，不暗示已上线。
- [ ] 导航顺序正确，GitHub 为最右侧且新窗口打开，语言控件为 Globe 图标。
- [ ] 中英文 key 同构，文案无标签能力回归。
- [ ] 官网仅使用黑白灰，在桌面与移动端无溢出或重叠。
- [ ] App light token 无黄 / 米色，dark theme 无回归。
- [ ] 相关静态测试、theme 测试、web lint 与 web build 通过。

## Out Of Scope

- 修改 Agent、工作流或后端实际能力。
- 重构 App 组件、布局或深色主题。
- 删除旧截图、原型或用户未提交产物。
- 新增定价、用户评价、客户 Logo 或无法证实的指标。
