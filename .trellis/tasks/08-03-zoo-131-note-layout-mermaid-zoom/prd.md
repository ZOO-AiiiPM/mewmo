# ZOO-131 笔记宽屏布局与 Mermaid 缩放

## Goal

减少笔记阅读页在宽屏下的无效留白，并让 Mermaid 预览在原位置支持双指缩放和拖动查看。

## Requirements

1. 放宽标题和正文的共享内容列，窄屏边距自动收紧且不得横向溢出。
2. Mermaid 图仍在当前代码块预览区域内显示，不打开弹窗或独立查看器。
3. 触屏双指捏合与触控板 pinch 缩放图表；包括最小缩放在内都可用触摸或指针拖动。
4. 普通双指上下滚动继续滚动笔记，只有 pinch 手势拦截默认滚动。
5. 图表缩放范围有限，切换笔记或重新渲染后恢复默认状态。
6. Mermaid SVG 继续经过 Milkdown 的 DOMPurify sanitizer，不改变 Markdown 或代码块编辑行为。

## Acceptance Criteria

- [ ] 宽屏下标题、正文、代码块、表格和 Mermaid 可用宽度明显增加。
- [ ] 窄屏下保持合理内边距且无横向溢出。
- [ ] Mermaid 可连续 pinch 缩放，最小缩放时仍可拖动且手势结束无跳动。
- [ ] 普通滚动、文本选择、源码编辑和代码块退出行为不回归。
- [ ] 切换笔记或图表重渲染后缩放状态重置。
- [ ] 深色、浅色主题与生产构建通过。

## Out Of Scope

- Mermaid 弹窗、工具栏、导出、保存缩放状态。
- 修改 Markdown、Mermaid 语法或服务端数据。
