### 关键技术决策
- **JWT 而非 DB 表**：HS256 手写（零依赖，复用 NEXTAUTH_SECRET），15min TTL，不改 schema（项目无 migration，db:push 有风险）
- **防枚举**：forgot-password API 无论用户是否存在返回 `{ok:true}`
- **邮件链接用请求 origin**：`new URL(request.url).origin`，preview/production 自动适配，不再读 `env.NEXTAUTH_URL`
- **不验旧密码**：reset-password 直接 prisma.user.update，不复用 `updateAccountPassword`（它对有密码用户强制验旧密码会卡住重置）
- **邮件 URL 不含 email**：JWT 内含 email，避免日志/referrer 泄露

### 发现的工具链陷阱（长期有用，已写入 MEMORY.md）
1. `NODE_OPTIONS=--use-system-ca` 让 Next.js 16 Turbopack build 报 `ERR_WORKER_INVALID_EXEC_ARGV`，要 `NODE_OPTIONS="" pnpm build`
2. `git fetch/push` 本网络会 HTTP2 framing 失败，用 `git -c http.version=HTTP/1.1`
3. `apps/web/src/lib/*.test.ts` 不在 `pnpm test:unit` 覆盖内，单独 `npx vitest run <path>`
4. tsc 报 `aiRun`/`contentEmbedding` 不存在 = Prisma client stale，先 `pnpm db:generate`
